Install on iPhone or iPad

Safari doesn't allow one-tap install buttons, so it takes two quick taps:

  1. Tap the Share button in Safari's toolbar (the square with an arrow pointing up).
  2. Scroll down and tap Add to Home Screen, then tap Add.
  1. Tap the ⋮ menu in Firefox's toolbar.
  2. Tap Install or Add to Home screen.
